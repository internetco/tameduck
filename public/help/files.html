Find and organize your files

Everything your Ducks and teammates share ends up in Files. Find it, sort it into folders, and tidy up.

6 stepsChecked against the app on 5 October 2026

Step123456
  1. 1

    Step 1: Open Files

    Click Files in the sidebar.

    You see files shared in chats and documents your Ducks wrote. All files shows everything; Unfiled holds what isn’t in a folder yet. Click a folder to look inside, and use the path at the top to go back.

    Good to know. Files opened from a chat or a Duck only show that chat’s or that Duck’s files.

  2. 2

    Step 2: Make folders

    Click New folder, type a name, then click Create folder.

    Inside a folder, New folder here makes one inside it. The pencil renames a folder. The bin deletes a folder, but only an empty one.

    Good to know. Folders only sort files. Deleting a folder never deletes files.

  3. 3

    Step 3: Upload a file or write a document

    Click Upload (or Add → Upload a file), pick the files, choose the chat under Share it in, and upload.

    Everyone in that chat can open them. Up to 10 files at once, 25 MB each; empty files are refused. To write one here, click New document (or Add → New document).

  4. 4

    Step 4: Find a file

    Type in Find a file, or click a file type to narrow the list.

    Archived shows files archived from this view; open one and click Restore file to bring it back. No files match? Change the search or the folder, or click Show all files.

  5. 5

    Step 5: Open a file and its menu

    Click a file to see it, then click its ••• button for more.

    What you can do depends on the file and your access: Show in chat, Show in ticket, Download, Move to folder…, and for shared files View history.

  6. 6

    Step 6: Move, archive or delete

    Click Move to folder… to file it, or Archive file to take it out of Current.

    Archived files wait under Archived; Restore file brings them back.

    Watch out. Delete file… is permanent: the file also disappears from the chat or ticket it was shared in. Click Keep it if you’re not sure.

That’s it.
