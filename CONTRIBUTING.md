# Contributing to TameDuck

TameDuck is maintained by Internet Company BV For maintainer questions,
contact [info@tameduck.com](mailto:info@tameduck.com).

This repository initially contains reviewed application release snapshots. Issues
and focused pull requests are welcome. Accepted patches may be incorporated into
the next release snapshot; maintainers preserve human contributor credits in
source notices and release notes.

Run `npm test` and `npm run build` for the included checks. Describe the concrete
behavior changed and relevant validation. Avoid real credentials, private user
data, or production account details in fixtures and reports.

Contributions to TameDuck's original code use AGPL-3.0-only. Retain upstream
copyright and license notices, and identify the origin/license of new third-party
material. Do not submit a new dependency or copied asset without its attribution.
