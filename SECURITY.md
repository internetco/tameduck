# Security

Please report security problems privately, not in a public issue.

Email [info@tameduck.com](mailto:info@tameduck.com) with what you found, how to reproduce it, and what someone could do with it. If this repository shows a **Report a vulnerability** button, you can use that instead.

We will confirm that we got your report and keep you posted while we fix it. Fixes go into the latest release, so please check against that version.

This covers the TameDuck application in this repository and TameDuck Cloud. Please do not access other people's data, run denial-of-service tests against TameDuck Cloud, or try social engineering.
